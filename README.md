# mardi_gras_rideshare

## Whisk Frontend Prototype

- Open `index.html` in a browser (or use `Live Server` in VS Code).
- Default state is Mardi Gras Mode OFF.
- Click the `Mardi Gras Mode` pill to toggle ON.
- Slider updates pickup pins for 1-5 block walk preference.

No backend needed; all data is hardcoded per requirements.
